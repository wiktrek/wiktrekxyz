# My problem with the internet
I've been using the internet basically since I was born and If it wasn't for the internet I wouldn't be where/who I am. Since I started using it there were many different trends but now almost every website looks the same ( Yes I know my website has the same problem ) and has some of the problems that I will mention later.
# All websites look the same now
I heard this some time ago, but I don't think that its bad. When it comes to design, there will always be trends. You don't need to follow them just make your own website css with js allows you to do almost anything.
More and more people make their own websites with AI now, that might mean that there will be much more websites looking the same. It might also mean that some people will learn how to code and make their own stuff. We will see the results in a few years.
# Downtime 
My website uses cloudflare for dns and vercel for hosting. Which means if either vercel ( or aws ) or cloudflare goes down my whole website stops working. 

Almost every popular website uses some sort of provider for something. You could say that you can just have multiple providers but how do you do that. When you have 2 hosting providers how do you switch between them? What if the thing you use for load balancing goes down? 
## "A chain is as strong as its weakest link"
You can never be sure that everything will work. The problem with modern internet is that when for example [cloudflare went down](https://blog.cloudflare.com/18-november-2025-outage/) almost every single website I use was unusable.
# Selfhosting
"Just selfhost most of your stuff" - That fixes some of the problems, but what If google is down and no one can find your website. "Yea, but not everyone uses google" - ~90% of people use google. Selfhosting your stuff is great If you just do It for your family or yourself, but when you want to scale it it has the same problems as every other solution.
# Advantages of the internet being so interlocked
Most of the requests could be faster because the servers are in the same data centers. I can't think of more advantages.
# Are there any solutions???
[I2P](https://i2p.net/en/)/[Yggdrasil](https://yggdrasil-network.github.io/) are really cool and solve some of the problems, but we can't just replace the internet. I know many "tech" people irl and I still haven't met anyone that had heard about either of these 2.
